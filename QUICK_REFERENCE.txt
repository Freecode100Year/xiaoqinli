  Xiaoqinli 是面向 AI Agent 的 AST-First 安全转译器。
  输入 .xql.json (结构化 JSON AST) → 输出 42+ 种目标语言/平台的原生代码。
  单一 Go 二进制 · 零第三方依赖 · 零运行时。


══════════════════════════════════════════════════════════════════════
  设计宪法
══════════════════════════════════════════════════════════════════════

  ① 极简      — 最少概念，最少代码
  ② 安全      — 能力安全 (@grant)，静态验证
  ③ 高性能    — 单二进制，即时编译，无 GC 压力


══════════════════════════════════════════════════════════════════════
  核心包结构 (6+1)
══════════════════════════════════════════════════════════════════════

  main.go      CLI 入口 (~170 行)
  ─────────────────────────────────────────────────────────────────
  ast/         24 种 AST 节点定义 + JSON 解析器
               + 内容寻址哈希 (CAS) + 二进制编解码器 (codec)
  ─────────────────────────────────────────────────────────────────
  check/       类型检查器 + 效果推断 + 能力安全验证 (@grant)
  ─────────────────────────────────────────────────────────────────
  codegen/     42 个后端代码生成器
               (go / rust / ts / py / java / csharp / kotlin /
                swift / dart / zig / ...)
  ─────────────────────────────────────────────────────────────────
  compiler/    公共库 API — 6 个导出函数:
               ParseAST, Validate, Compile,
               CompileFromFile, GetSupportedTargets, GetVersion
  ─────────────────────────────────────────────────────────────────
  server/      MCP (stdio + HTTP) + REST API + Skills 技能分发
  ─────────────────────────────────────────────────────────────────
  vfs/         会话内存文件系统


══════════════════════════════════════════════════════════════════════
  静态分析流水线
══════════════════════════════════════════════════════════════════════

  JSON 解析        类型检查        效果推断        能力安全验证        代码生成
  (XQL_E1xx)  ──▶  (XQL_E2xx)  ──▶  (XQL_E2xx)  ──▶  (XQL_E3xx)  ──▶  (XQL_E4xx)
      │                │                │                │                │
      ▼                ▼                ▼                ▼                ▼
   解析失败?        类型错误?        副作用冲突?      权限缺失?        目标不支持?
   → 终止           → 终止           → 终止           → 终止           → 终止


══════════════════════════════════════════════════════════════════════
  三通道接入
══════════════════════════════════════════════════════════════════════

  通道                  场景                          协议
  ───────────────────────────────────────────────────────────────
  MCP (stdio / HTTP)    Claude Code, Cursor 等        JSON-RPC over stdio / SSE
  REST API              脚本 / HTTP 客户端            HTTP JSON
  Skills                go:embed 技能分发             内嵌资源


══════════════════════════════════════════════════════════════════════
  CLI 命令速查
══════════════════════════════════════════════════════════════════════

  编译:
    xql compile --file <path> --target <lang> [--out <output>]

  校验:
    xql validate --file <path>

  目标列表:
    xql targets

  MCP stdio:
    xql stdio

  HTTP 服务:
    xql http [:port] [--mode rest]

══════════════════════════════════════════════════════════════════════
  库 API 使用示例
══════════════════════════════════════════════════════════════════════

  import "xiaoqinli/compiler"

  result := compiler.CompileFromFile("app.xql.json", "go", "")

  // result.Success   — 是否成功
  // result.Code      — 生成的代码
  // result.Errors    — 错误列表


══════════════════════════════════════════════════════════════════════
  支持的 42 种目标语言/平台
══════════════════════════════════════════════════════════════════════

  系统级       go, rust, c, cpp, zig, d, v, nim, vala
  JVM/CLR      java, kotlin, csharp, dart, groovy
  脚本         py, ts, ruby, lua, php, perl, julia, crystal, awk
  函数式       haskell, ocaml, elixir

  专属         shortcut (iOS 快捷指令), chrome (浏览器插件)


══════════════════════════════════════════════════════════════════════
  错误码速查
══════════════════════════════════════════════════════════════════════

  XQL_E1xx     JSON 解析阶段错误
  XQL_E2xx     类型检查 / 效果推断错误
  XQL_E3xx     能力安全验证错误 (@grant)
  XQL_E4xx     代码生成阶段错误
